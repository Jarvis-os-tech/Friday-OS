# FRIDAY - AI Voice Assistant

Minimalist, seamless plain voice interface powered by real-time speech-to-speech AI, autonomous research grounding, modular skills, and multi-input intelligence.

---

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js** (v18+ recommended)

### 2. Set API Key
Create a `.env` or `.env.local` file with your Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Application

#### Web Application (Dev Mode):
```bash
npm run dev
```

#### Production Build:
```bash
npm run build
```

#### Run Production Server:
```bash
npm start
```
